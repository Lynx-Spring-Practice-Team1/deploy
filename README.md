# Project Setup Guide

Follow these steps to get your local development environment up and running using Docker.

## Prerequisites

*   [Docker Desktop](https://www.docker.com/products/docker-desktop/) installed and running.
*   A terminal/command prompt.

---

## Getting Started

### 1. Configure Environment Variables
Before launching the containers, you need to create a `.env` file. We provide a template file called `.env.example` with the necessary keys.

After that run docker compose

**Windows / macOS / Linux:**
```bash
docker compose up -d
